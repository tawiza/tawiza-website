À propos

qui

Tawiza est porté par une seule personne. Le code est ouvert, les analyses sont sourcées, les méthodes sont documentées. L'identité du mainteneur n'est pas publique. Ce qui l'est, c'est le travail.

Jugez le travail, pas le CV. Si le projet vous parle, il peut devenir collectif : c'est tout l'objet de la page Contribuer.

Pourquoi « on » et pas « je ». Ce site dit « on ». Derrière ce « on », il y a une personne. C'est un choix d'écriture, pas de modestie. Une analyse n'appartient pas à celui qui l'écrit. Elle appartient aux données, aux sources, et au lecteur qui vérifie. Le « je » implique une autorité. Le « on » implique une méthode. C'est la méthode qui compte.
statut

Tawiza est en phase de construction. Les analyses publiées sont réelles : chaque chiffre est sourcé, chaque source est vérifiable. L'outil technique (collecte automatisée, agent IA, dashboard) est en développement. Ce qui est publié fonctionne. Ce qui ne fonctionne pas encore n'est pas publié.

pourquoi « tawiza »

Tawiza vient de l'amazigh. C'est une forme d'entraide collective pratiquée dans les communautés amazighes. Quand quelqu'un a besoin de construire sa maison, de récolter ses champs ou de préparer un événement, la communauté se mobilise. Pas de contrat, pas de rémunération. Juste la certitude que quand tu auras besoin, les autres seront là.

Construire ensemble quelque chose que personne ne pourrait faire seul.

transparence

Le site utilise Plausible Analytics : sans cookies, conforme RGPD, pas de tracking individuel.

La plateforme Tawiza (en développement) collecte une télémétrie anonyme et opt-out via PostHog hébergé en UE. Aucune IP, aucun email, aucun contenu de requête. Le code de télémétrie est 100 % transparent.

Pour désactiver : TELEMETRY_ENABLED=false dans votre .env.
