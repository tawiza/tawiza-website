Un glyph unique par page,
reproductible par son seed.

Chaque page de Tawiza porte un glyph génératif déterministe. Le seed est dérivé du slug de la page : donc /articles/rga-silence produira toujours le même motif, sur tous les navigateurs, dans tous les modes. C'est un objet mesuré — avec son cadre-mire, ses marqueurs d'angle, et son label lisible à l'œil nu.

Les 6 règles du système

  1. Déterministe Le seed dérive du pathname (FNV-1a hash). Même URL = même glyph, sur tous les navigateurs, aujourd'hui et dans 5 ans.
  2. Cadré comme une mire Marqueurs d'angle ocre aux 4 coins, petits tirets de graduation sur les 4 côtés. L'objet est mesuré, pas décoratif.
  3. Trois couches L0 = trame de points discrets. L1 = hachures directionnelles. L2 = accents rares (croix, points carrés) dans une couleur d'alerte.
  4. Vocabulaire fini 6 types de marques seulement : diagonal, anti-diagonal, horizontal, vertical, point, croix. Pas de formes libres.
  5. Densité dérivée du slug Les slugs courts sont plus denses, les longs plus aérés. Un titre d'article tient visuellement différemment d'un code territoire.
  6. Palette minérale seule Ocre #b45309, terre #C1554D, forêt #2D6A4F, encre #1a1612. Aucune autre couleur n'est autorisée dans le système.
