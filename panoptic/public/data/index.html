// panoptic · données brutes

Les données publiées, telles qu'on les a utilisées.

416 projets agrivoltaïques croisés, 133 contestations CNPrV, 4 registres publics fusionnés inter-sources. Tu peux tout télécharger. Licence CC-BY-SA-4.0.

I · SQLite complèteLa base embarquée dans la CLI panoptic

C'est le fichier que panoptic update télécharge pour rafraîchir la DB locale. Schéma lisible, projets + contestations + matches + opérateurs. Le plus pratique si tu veux faire tes propres requêtes SQL.

  • SQLite · 372 KB panoptic.sqlite base complète : projects, contestations, project_contestation_match, source_freshness, meta
  • JSON · 1 KB manifest.json métadonnées version + compteurs + SHA-256 signé de la SQLite (vérifie l'intégrité avant usage)

II · ProjetsListés plat ou géolocalisés

Les 416 projets fusionnés après croisement ADEME + MRAe + projets-environnement. Pour traiter dans un tableur, un notebook ou un outil de carto.

  • JSON · 532 KB projects.json tous les projets en JSON plat, avec nom, commune, opérateur, puissance, surface, statut, sources
  • GeoJSON · ≈500 KB projects.geojson projets avec latitude / longitude pour afficher sur une carte (QGIS, Leaflet, MapLibre, etc.)
  • JSON · 17 KB projects-by-dept.json agrégats par département : nombre de projets, puissance totale, hectares, top opérateurs

III · ContestationsLes 133 victoires CNPrV

Le registre associatif des mobilisations locales victorieuses contre des projets photovoltaïques sur terres agricoles ou naturelles. Source : Coordination Nationale Photorévoltée.

  • JSON · 64 KB contestations.json toutes les contestations en JSON plat : commune, date, acteur, statut, résumé
  • GeoJSON · ≈90 KB contestations.geojson contestations géolocalisées pour cartographie

IV · Le code qui a produit ces données

La règle de fusion inter-sources, les collectors, les filtres de métadonnées MRAe : tout est ouvert et reproductible. Fork, bug, pull request bienvenus.
